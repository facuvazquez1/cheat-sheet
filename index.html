Cheat sheet

Atajos de teclado que uso todos los días

Mi lista personal, organizada por herramienta. Cada atajo tiene su combinación, un título corto y una explicación más completa.

Windows

Alt + Tab

Cambiar de ventana

Abre el selector de ventanas de Windows. Mientras mantenés Alt apretado, cada toque de Tab avanza a la siguiente ventana abierta; al soltar, saltás a la seleccionada. Sumá Shift para ir en sentido contrario.

VS Code

Ctrl + CapsLock + `

Nueva terminal

Abre una terminal nueva dentro de VS Code, en el panel inferior, sin salir del editor. Útil para tener una terminal corriendo el servidor de Vite y otra libre para comandos de Git.
